# Publication sur GitHub

Décompressez cette archive et publiez le contenu du dossier `hello-watt-home-assistant` à la racine du dépôt https://github.com/elmomotito/homeassistant-hellowatt.

À la racine doivent se trouver `repository.yaml`, `README.md`, `docs/` et `hellowatt_daily/`. Ne publiez pas uniquement le ZIP et ne créez pas un niveau de dossier supplémentaire autour de ces fichiers.

Conservez `home_id`, les adresses e-mail et les mots de passe vides dans les fichiers publics. Les utilisateurs saisissent leurs accès dans Home Assistant après installation.

Le dépôt n’a pas été modifié automatiquement : ces fichiers sont prêts à être ajoutés par son propriétaire. Après publication, testez le bouton du README et l’installation depuis le magasin. Pour les prochaines mises à jour du script, augmentez `version` dans `hellowatt_daily/config.yaml`.
